# Security Policy

## 1. Supported Versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |
| < 0.1.0 | No |

---

## 2. Reporting a Vulnerability

If you discover a security vulnerability or execution sandbox vulnerability in CeilBreak, please send a report to `shahriar.ahmed.seam@gmail.com`.

Please include:
1. Description of the vulnerability.
2. Steps to reproduce the issue or proof-of-concept code.
3. Potential impact and attack vector.

We appreciate responsible disclosure and will respond within 48 hours.
